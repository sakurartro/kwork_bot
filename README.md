# Kwork Parser Telegram Bot

Телеграм-бот для парсинга новых заказов с фриланс-биржи [Kwork](https://kwork.ru/)
с отбором через нейросеть **Gemini** и автогенерацией отклика + промпта для Claude Code.

📄 Подробный план и архитектура — в [PLAN.md](./PLAN.md).

## Возможности
- `/start` — парсит новые заказы, прогоняет через Gemini («может ли ИИ сделать всё сам?»),
  по одобренным присылает: ссылку, копируемое название/описание, человечное сообщение
  заказчику и подробный промпт для Claude Code.
- `/chat` — вставляете сообщение клиента → бот пишет человечный ответ.
- Защита от блокировок: рандомные задержки 90–150 с, ротация User-Agent, прокси, backoff.

## Быстрый старт (после реализации)
1. `python -m venv venv && source venv/bin/activate`
2. `pip install -r requirements.txt`
3. Скопировать `.env.example` → `.env` и заполнить ключи.
4. `python -m src.main`

> ⚠️ Автопарсинг может нарушать правила Kwork. Используйте на свой риск.
